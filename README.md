# Стартовий проєкт

Потрібна ОС Linux: GitHub Codespaces, WSL2 у Windows, власний Linux або сервер коледжу.

1. Відкрийте проєкт у GitHub Codespaces (Code → Codespaces → Create codespace) або локально в Linux: `python3 -m venv .venv`, `source .venv/bin/activate`, `pip install -r requirements.txt`.
2. Знайдіть свої файли в папці `tasks/` і реалізуйте їх за картками.
3. Запускайте відкриті тести: `pytest`.
4. Змінюйте лише файли в `tasks/` (і за бажанням `tests/test_my.py`).
5. Теоретичні завдання 11-15 не мають тестів: відповідь пишіть у файлі `answers/task_NN.md` під рядком «Відповідь:» (формулювання завдання вже у файлі). Змінюйте лише ті файли `answers/`, які ви обрали.
